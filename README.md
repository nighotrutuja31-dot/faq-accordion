# FAQ Accordion

## 📌 Project Overview

The FAQ Accordion is an interactive web component developed using HTML5, CSS3, and JavaScript.

Users can click on a question to expand its answer. Clicking another question automatically closes the previously opened answer.

## 🚀 Features

- 8 FAQ questions
- Expandable answers
- Collapsible answers
- Active question state
- Smooth animations
- Responsive design
- Mobile-friendly interface
- JavaScript DOM manipulation
- classList.toggle()
- Event handling

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
